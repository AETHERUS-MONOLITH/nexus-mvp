# Security Policy

## Reporting Security Issues

Please do not open public issues for secrets, vulnerabilities, exploit details,
or reports that could put users or deployments at risk.

Use GitHub private vulnerability reporting if it is enabled for this
repository. If private vulnerability reporting is not available, open a minimal
public issue asking for a secure contact path. Do not include sensitive details
in that public issue.

Useful reports include affected versions or commits, impact, reproduction
steps, and any safe proof of concept that does not expose secrets or enable
abuse.
